- Verified DMA-based data transfer between MAC and memory
- Analyzed MII interface communication between MAC and PHY

### **[AXI Universal Verification Component](https://github.com/Subbu-48D/AXI_UVC)**
Designed and deployed advanced AXI UVC with comprehensive testbench environments.

- Generated and verified read/write transactions with burst configurations

- Handled overlapping transactions in testbench-level verification environments

- Achieved 100% functional coverage using assertions and coverage models
